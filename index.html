Coloca una superficie de agua luminosa y una bruma turquesa sobre el espacio real, directamente desde tu teléfono.

Preparando la experiencia… Esta versión necesita un teléfono y un navegador compatibles con WebXR AR.

Al entrar en AR, mueve lentamente el teléfono para detectar el suelo. Apunta al lugar deseado y toca la pantalla para colocar el efecto.

Compatibilidad del dispositivo

AR espacial no disponible aquí

Este navegador no expone WebXR immersive-ar. Prueba con un dispositivo Android compatible y Chrome actualizado. En muchos iPhone, WebXR AR no está disponible en Safari, así que una experiencia espacial requiere una solución alternativa o una aplicación nativa.

El sitio sí está publicado como página web segura. Para activar el modo espacial se necesita soporte del navegador y del dispositivo, no otro archivo del proyecto.
