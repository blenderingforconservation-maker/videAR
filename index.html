Compatibilidad del dispositivo

AR espacial no disponible aquí

Este navegador no expone WebXR immersive-ar. Prueba con un dispositivo Android compatible y Chrome actualizado. En muchos iPhone, WebXR AR no está disponible en Safari, así que una experiencia espacial requiere una solución alternativa o una aplicación nativa.

El sitio debe servirse por HTTPS (por ejemplo GitHub Pages). Para activar el modo espacial se necesita soporte del navegador y del dispositivo.
